## 📊 Функционал

Проект представляет собой систему для беспроводного сбора и передачи данных с датчиков на базе Arduino Nano и NRF24L01+ на приемник ESP8266. Данные могут отображаться в реальном времени, а также сохраняются в базе данных для дальнейшего анализа.

---

### **🔧 Основные функции**
1. **Передатчик (Arduino Nano + NRF24L01+)**:
   - Измерение температуры и влажности с помощью датчика DHT22.
   - Передача данных по радиоканалу (NRF24L01+) каждые 5 секунд.
   - Поддержка стабильного соединения даже на расстоянии до 100 м (в открытом пространстве).

2. **Приемник (ESP8266 + NRF24L01+)**:
   - Прием данных от передатчика по радиоканалу.
   - Отправка данных на сервер (например, ThingSpeak, Blynk или локальный MQTT-брокер) через Wi-Fi.
   - Возможность вывода данных в Serial Monitor для локального мониторинга.

3. **Дополнительные возможности**:
   - Логирование данных в файл (через Python-скрипт или SD-карту).
   - Интеграция с веб-интерфейсом для визуализации данных (графики, уведомления).
   - Поддержка нескольких передатчиков для мониторинга в разных зонах.

---

### **📡 Схема работы**
1. **Передатчик**:
   - Считывает данные с датчиков.
   - Упаковывает их в структуру (`temp`, `hum` . . . ).
   - Отправляет на приемник через NRF24L01+.

2. **Приемник**:
   - Принимает данные от передатчика.
   - Подключается к Wi-Fi (ESP8266).
   - Отправляет данные на выбранную платформу (например, ThingSpeak) или выводит в Serial Monitor.

3. **Визуализация**:
   - Данные отображаются в веб-интерфейсе или мобильном приложении (например, Blynk).
   - Возможна настройка уведомлений при выходе значений за заданные пределы.
   - SCADA система (WinCC)

---

### **🛠 Технические особенности**
- **Частота передачи**: 2.4 ГГц (NRF24L01+).
- **Дальность связи**: До 100 м (в идеальных условиях).
- **Питание передатчика**: PowerBank (5V).
- **Питание приемника**: Через USB или внешний источник 5V.
- **Протокол связи**: SPI (для NRF24L01+), HTTP/MQTT (для ESP8266).

## Компоненты  
- Передатчик: Arduino Nano + NRF24L01+ + DHT22.  
- Приемник: ESP8266 + NRF24L01+.  

## Настройка  
1. Прошейте `transmitter.ino` на Arduino.  
2. Прошейте `receiver.ino` на ESP8266.  
3. Запустите `serial_reader.py` на ПК.  

## Структурная схема:
```
Датчик -> Передатчик -> Приемник -> Wi-Fi -> [ Облако ]
|
v
[ Веб-интерфейс / Мобильное приложение / SCADA ]
```
