# AgroMonitoring


## 🌱 О проекте
Система беспроводного мониторинга микроклимата на базе ESP-12E (передатчик) и ESP8266 NodeMCU (приемник) с использованием радиомодулей NRF24L01+. Позволяет удаленно отслеживать температуру и влажность в сельскохозяйственных помещениях, теплицах или складах.

## 📌 Основные характеристики
- **Дальность связи**: до 100м (с модулями PA/LNA)
- **Частота обновления**: каждые 5 секунд
- **Энергопотребление**: 
  - Передатчик: ~80мА в активном режиме
  - Приемник: ~120мА при работе Wi-Fi
- **Точность измерений**:
  - Температура: ±0.5°C (DHT22)
  - Влажность: ±2% (DHT22)

## 🛠 Состав системы

3. **Периферия**:
   - Макетная плата
   - Провода "папа-папа"/"папа-мама"
   - Конденсаторы 10мкФ (для стабилизации питания)

## 📊 Функционал

Проект представляет собой систему для беспроводного сбора и передачи данных с датчиков на базе ESP-12E и NRF24L01+ на приемник ESP8266. Данные могут отображаться в реальном времени, а также сохраняются в базе данных для дальнейшего анализа.

---

### **🔧 Основные функции**
1. **Передатчик (ESP-12E + NRF24L01+)**:
   - Измерение температуры и влажности с помощью датчика DHT22.
   - Передача данных по радиоканалу (NRF24L01+) каждые 5 секунд.
   - Поддержка стабильного соединения даже на расстоянии до 100 м (в открытом пространстве).

2. **Приемник (ESP8266 + NRF24L01+)**:
   - Прием данных от передатчика по радиоканалу.
   - Отправка данных на сервер (например, ThingSpeak, Blynk или локальный MQTT-брокер) через Wi-Fi.
   - Возможность вывода данных в Serial Monitor для локального мониторинга.

3. **Дополнительные возможности**:
   - Логирование данных в файл (через Python-скрипт или SD-карту).
   - Интеграция с веб-интерфейсом для визуализации данных (графики, уведомления).
   - Поддержка нескольких передатчиков для мониторинга в разных зонах.

---

### **📡 Схема работы**
1. **Передатчик (ESP-12E)**:
   - Считывает данные с датчиков.
   - Упаковывает их в структуру (`temp`, `hum` . . . ).
   - Отправляет на приемник через NRF24L01+.

2. **Приемник**:
   - Принимает данные от передатчика.
   - Подключается к Wi-Fi (ESP8266).
   - Отправляет данные на выбранную платформу (например, ThingSpeak) или выводит в Serial Monitor.

3. **Визуализация**:
   - Данные отображаются в веб-интерфейсе или мобильном приложении (например, Blynk).
   - Возможна настройка уведомлений при выходе значений за заданные пределы.
   - SCADA система (WinCC/masterSCADA)

---

### **🛠 Технические особенности**
- **Частота передачи**: 2.4 ГГц (NRF24L01+).
- **Дальность связи**: До 100 м (в идеальных условиях).
- **Питание передатчика**: 3V.
- **Питание приемника**: Через USB или внешний источник 5V.
- **Протокол связи**: SPI (для NRF24L01+), HTTP/MQTT (для ESP8266).

## Настройка  
## 💻 Инструкция по настройке

### 1. Подготовка среды
```bash
# Установка PlatformIO
pip install platformio

# Клонирование репозитория
git clone https://github.com/ваш-репозиторий/AgroMonitoring.git
cd AgroMonitoring
```
### 2. Прошивка передатчика
```
cd firmware/transmitter
pio run --target upload --upload-port /dev/ttyUSB0
```
### 3. Прошивка приемника
```bash
cd firmware/receiver
pio run --target upload --upload-port /dev/ttyUSB1
```
### 4. Настройка Wi-Fi
Отредактируйте в коде:

```cpp
// Для приемника:
const char* ssid = "ВАШ_WiFi";
const char* password = "ВАШ_ПАРОЛЬ";
```

```
Датчик -> Передатчик -> Приемник -> Wi-Fi -> [ Облако ]

v

```
